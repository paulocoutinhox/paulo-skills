# Research method and limits

Baseline date: **2026-11-05**. Each skill includes its own source notes and focused operational references. Research favored the actual specification, platform documentation, public implementation source, framework maintainers, security standards, and institutional normalization guidance. Marketing references supplement official creator lessons with practitioner material. No unviewed video transcript or inaccessible book is represented as read evidence.

## Evidence categories

Official requirements are tied to the exact target product, format, version, or account surface. Owner preferences are labeled as such. Marketing advice is a hypothesis to evaluate against the audience. A missing current source remains an explicit verification task rather than a fabricated constant.

The portable skill format was checked against [the specification](https://agentskills.io/specification), [Codex documentation](https://learn.chatgpt.com/docs/build-skills), [Claude Code documentation](https://code.claude.com/docs/en/skills), and the actual [reference implementation](https://github.com/agentskills/agentskills/tree/main/skills-ref).

## Publishing and book production

Print requirements were compared across the requested production services. The working publication instructions remain provider-neutral. Source evidence included the [current production options form](https://bok2.com.br/), [help catalog](https://bok2.com.br/central-ajuda), [paperback cover geometry](https://kdp.amazon.com/en_US/help/topic/G201953020), [manufacturing submission rules](https://kdp.amazon.com/en_US/help/topic/G201857950), and [digital-cover format rules](https://kdp.amazon.com/pt_BR/help/topic/G200645690).

The static commercial-help page initially omitted its answer bodies. The public page's client data was subsequently retrieved and read, including [its file-submission instructions](https://bok2.freshdesk.com/support/solutions/articles/66000488631-como-devo-enviar-os-meus-arquivos-). That help specifies PDF/X-1a, CMYK, outlined text, marks/bleed, 300 ppi images, and a flat cover including flaps. Its format answers list common trim sizes. Its template answers conflict over a generator versus no downloadable templates, so the skill still requires the real job specification.

The separate historical technical article was discoverable in indexing, but its live body could not be reliably retrieved. Its numerical 4–5 mm bleed is not treated as a verified current contract. The active options form also does not publicly establish every stock and binding choice. The skill does not invent paper availability or manufacturing approval.

The current paperback help also has inconsistent 79/80-page wording for spine text. The skill uses an explicitly conservative 80-page baseline and still requires the template. Hardcover, spiral, saddle stitch, flaps, and alternate papers cannot inherit the paperback spine formula blindly. A press PDF is distinct from a PNG artwork master.

ABNT edition checks used [university normalization guidance](https://sibpesquisa.ufes.br/normas.html). The current references edition is NBR 6023:2025, alongside NBR 10520:2023 and NBR 14724:2024. Full compliance requires the authorized standard and applicable institutional guide. Arial 12 and paragraph indentation are clearly identified working conventions rather than universal mandates.

## Volatile platform facts

YouTube's [current thumbnail help](https://support.google.com/youtube/answer/72431?hl=en) differentiates desktop and mobile upload limits and now recommends 4K canvases. The owner's 2 MB JPEG preset remains an explicitly selected conservative derivative.

YouTube Studio describes its description limit in characters while the [Data API](https://developers.google.com/youtube/data/reference/rest/v3/videos) uses UTF-8 bytes. TikTok's Direct Post endpoint uses UTF-16-based caption accounting. X uses weighted text and URL normalization. The utilities keep these distinctions explicit.

Live Instagram official pages returned access/rate-limit errors. Indexed API wording and current secondary guidance indicate a discrepancy between historical API hashtag ceilings and newer app restrictions. The skill uses at most five relevant hashtags as a conservative editorial default and requires verification for the actual account/interface. X paid long-post help also varies, so no universal paid ceiling is hardcoded.

## Software, review, and security

Language profiles use official framework guidance and distinguish owner conventions from language requirements. Apple documentation frontends required a separately retrieved official Markdown/data body, which was read to verify ARC and strict-concurrency guidance. Verify exact APIs for the chosen deployment target before implementation.

Review research inspected public review implementation and action documentation. It does not make an unsupported popularity ranking. Security research uses OWASP Top 10:2025, ASVS 5.0.0, API Top 10:2023, MASVS, and the older incubator desktop awareness catalog with their different scopes stated.

Registry publication research distinguishes package files from account trust. npm and PyPI have different first-publication setup paths, and current npm publisher settings distinguish staged and direct publish permissions. A ready workflow does not imply that an unavailable registry account was configured or that a real release was published.

## Refresh policy

Recheck tool and dependency versions, publishing requirements, platform limits, print templates, security standard versions, and current style editions before consequential operational use. Update the affected skill, references, templates, usage guide, and checks together. Local format validation proves format consistency, not that external requirements have remained unchanged.
